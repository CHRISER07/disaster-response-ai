# DAB-200: Disaster Situational Awareness Benchmark

A multi-hazard benchmark comprising 200 curated disaster queries across 7 scenarios:
* Flood (80 queries)
* Wildfire (25 queries)
* Chemical / HAZMAT (25 queries)
* Building Collapse (20 queries)
* Typhoon / Cyclone (20 queries)
* Earthquake (15 queries)
* Fabricated-Emergency Hallucination Traps (15 queries)

## Citation
Albert et al., "Temporally Grounded Agentic Retrieval-Augmented Generation with Deterministic Safety Enforcement for Disaster Situational Awareness", IEEE 2026.
